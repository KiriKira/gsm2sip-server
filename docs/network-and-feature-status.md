## 实際网络场景

| 场景 | 已有行为 | 限制/后续 |
|---|---|---|
| 主机暂时断网 | 消息/事件保留在 PostgreSQL；SQLite 保存事件游标，恢复后分页补齐 | 离线期间不能即时提示；数据库丢失、删除应用数据等不属无损保证 |
| 旧机互联网断网但仍收到运营商短信 | 收件与待上传事件先原子写 SQLite WAL/FULL；服务端事务提交才 ACK | 前提是 Android 把 SMS_RECEIVED 交给应用且有权限；被强制停止/撤权时不能保证接收 |
| WSS 丢提示、连接重建 | WSS 只提示 sync_required；30 秒 HTTPS 补齐，网关失败退避至 5 分钟；网络恢复主动唤醒网关轮询 | Doze、系统限制和请求超时会延迟，30 秒不是接收 SLA |
| 服务端已收事件但 ACK 丢失 | 网关重投同 event_id/hash，服务端去重 | 不等于 modem 提供 exactly-once 发送语义 |
| 发短信请求超时/进程中断 | 同请求键、同正文可查状态/重试；modem 前先写 dispatching，中断后标 unknown，不自动重发 | 明确优先避免重复计费；unknown 需要核查，不能承诺自动完成 |
| 旧机长时间离线，短信任务未领取 | command 有 TTL，默认 300 秒、最大 3600 秒；过期拒绝执行 | “最终所有发送都成功”不成立，避免恢复后发送失去时效的短信 |
| 通知同步时进程退出、通知投递失败 | 消息与通知待发状态需要原子提交，投递成功后确认；重放可能替换同 ID 通知 | 首次历史同步刻意静默；用户关闭通知/后台或 OS 停止时无法保证提醒 |
| captive portal/假连网 | HTTPS/WSS 正常证书与主机名验证；失败显示同步问题并重试 | 未实现完整 portal 诊断；不跳过证书校验，不降为明文 |
| access 刷新时响应丢失 | refresh token 轮换已有实现 | 无幂等刷新/恢复窗口，可能需要重新配对；尚待专门修复与回归 |
| 单次离线历史量很大 | 事件游标可分轮推进，现有服务端不裁剪事件 | snapshot 页游标未持久化；未来加入事件留存前必须实现可恢复快照和 resync 协议 |
| 通话中断网/切换 IP | 当前无完整三端通话，网关 SIP 重注册并不续接原通话 | 必须实现同 call_id 状态恢复、媒体重协商、有限宽限期及最终挂机 |
| 带宽下降/丢包/抖动 | 网关只有静态 SDP codec 协商及有限 FIFO/静音补帧 | G.722 和 G.711 都约 64kbps 音频负载，切换不等于省带宽；无自动降码率、RTCP/PLC |

首次历史静默、消息正文不丢、通知可重放属于不同保证。
通知必须采用至少一次投递思路：先 durable pending，系统 notify 成功后才 ACK；
进程在 notify 与 ACK 之间退出可能重复提醒，不能同时保证绝不漏和绝不重复。

## 后续通话网络实现门槛

优先把前台完整通话实现并验证，再承诺锁屏/弱网能力。主机到媒体服务器腿
考虑 Opus 可变码率、FEC/PLC/DTX、受限 jitter buffer 与 RTCP loss/RTT 反馈；
网关现有 G.711/G.722 腿需要服务端转码评估，不以降低 TLS/SRTP 安全来降级。

短断网须有明确、有限的蜂窝腿保留期，用同 call_id 同步权威状态、重新协商
媒体/ICE；已取消、已超时的来电不能恢复振铃。完全无网络时没有远程音频，
超出宽限期须释放设备锁并挂机，不能无限保留蜂窝计费通话。

验收应覆盖双端换 Wi-Fi/蜂窝、断网 5/30/120 秒、限速、1/5/10% 丢包、抖动、
DNS/TLS 失败、服务端重启、通知权限撤销、进程在持久化边界退出与重启。
以上弱网语音策略尚未实现，不是现有能力声明。

## 短信与 Magisk 边界

短信使用 Android 标准订阅/SmsManager/SMS_RECEIVED、HTTPS 与 SQLite。
普通 APK 短信模式无需 su、Magisk 模块、录音权限或默认电话角色；
启动只请求 READ_PHONE_STATE、SEND_SMS、RECEIVE_SMS，后台通知另行申请。
SIM 身份不能稳定读取时采用本机人工确认，重启后需重新核对，绝不猜默认卡。

Android 对短信权限有安装器/受限权限策略；若普通安装不能授予 SEND_SMS 或
RECEIVE_SMS，必须解决标准安装授权条件，并明确提示不可用，不能偷偷调用 root。
目前没有实现默认短信应用角色所需的完整组件，不能把申请该角色当现有 fallback。
Magisk 的账户 broker、音频路由和特权历史迁移仅属于用户显式启动的语音路径。
